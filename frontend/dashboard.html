ESP32 Setup Tutorial

1. Setup Captive Portal

On boot, the ESP32 hosts a hotspot named AquaSense-Setup (Password: aquasense123). Connect and navigate to 192.168.4.1.

2. Hardcoded MQTT Settings

To keep things simple, the MQTT Broker is already hardcoded inside the firmware code:

  • Host: broker.hivemq.com
  • Port: 1883
3. Values to Input

You only need to configure two parameters on the setup webpage:

  • Device ID: Matches the assigned ID on dashboard.
  • MQTT Topic: Enter the exact topic you registered here (e.g. esp32/aquasense/data).
4. JSON Data Payload

The ESP32 publishes readings to your topic in this JSON format:

{
  "device_id": 1,
  "ph_level": 7.00,
  "turbidity": 1.50,
  "tds": 200.0,
  "temperature": 25.0,
  "ammonia": 0.02,
  "flow_rate": 10.00,
  "water_consumed": 0.05
}
